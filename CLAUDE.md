## Файл маршрутизації

**[ROUTING.md](ROUTING.md)** — файл для маршрутизації. Спершу відкривайте його: він містить таблицю «тема → MD-файл → сторінки книги». Не читайте всю папку книги — відкривайте лише файл потрібної теми.

## Структура

- `ROUTING.md` — індекс усіх книг і тем.
- `books/<ключ-книги>/` — по одному MD-файлу на тему (орган / система), назви `NN-назва.md`.

## Правила

- Текст отримано OCR-розпізнаванням скану, тож можливі помилки; ілюстрації не перенесено, збережено лише підписи до рисунків (блоки `>`).
- Номери сторінок у коментарях `<!-- стор. N -->` — друковані номери книги.
- Додаючи нову книгу: створіть папку в `books/`, розбийте її на тематичні MD-файли й додайте розділ у `ROUTING.md` та рядок у таблицю вище.
